## Qué hacer

1. Verificá que n8n arranque. En PowerShell, parado en la carpeta del proyecto:

   ```powershell
   $env:N8N_RESTRICT_FILE_ACCESS_TO = "<ruta absoluta de esta carpeta>"
   npx n8n
   ```

   Sin esa variable los nodos de archivo fallan con
   `Access to the file is not allowed`. No es un bug del workflow.

2. Si las rutas embebidas en `workflows/01-pasamanos.json` no coinciden con la
   ubicación real de la carpeta, **regenerá el JSON**, no lo edites a mano:

   ```
   python herramientas/gen_workflow.py workflows/01-pasamanos.json "<csv entrada>" "<csv salida>"
   ```

3. Importá el workflow en n8n, ejecutalo, y corré el verificador:

   ```
   python verificadores/v00_pasamanos.py
   ```

## Criterio de aceptación

`v00_pasamanos.py` devuelve **10 de 10 PASA** y exit code 0, corriendo sobre el
`salidas/salida_f00.csv` que produjo n8n en Windows.

celda, 45 teléfonos con cero inicial, 200 CUIL con guiones, 41 teléfonos con
texto `sin dato`, tildes intactas.
